# Supabase Hierarchy & Thumbnails Migration

Copy and paste the following SQL into your **Supabase SQL Editor** to support the new folder hierarchy and cross-device thumbnails.

```sql
-- ==========================================
-- 1. ENHANCE FILES TABLE (Thumbnails)
-- ==========================================
ALTER TABLE public.files
ADD COLUMN IF NOT EXISTS thumbnail_remote_path TEXT,
ADD COLUMN IF NOT EXISTS thumbnail_size BIGINT,
ADD COLUMN IF NOT EXISTS thumbnail_width INTEGER,
ADD COLUMN IF NOT EXISTS thumbnail_height INTEGER,
ADD COLUMN IF NOT EXISTS thumbnail_hmac TEXT;

-- ==========================================
-- 2. CREATE VAULT FOLDERS TABLE
-- ==========================================
CREATE TABLE IF NOT EXISTS public.vault_folders (
    id TEXT PRIMARY KEY, -- Using TEXT to match Client-side UUID string
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    name TEXT NOT NULL,
    color INTEGER,
    icon TEXT,
    parent_id TEXT REFERENCES public.vault_folders(id) ON DELETE CASCADE,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Enable RLS
ALTER TABLE public.vault_folders ENABLE ROW LEVEL SECURITY;

-- RLS Policies for Folders
CREATE POLICY "Users can manage their own folders"
ON public.vault_folders FOR ALL
USING (auth.uid() = user_id);

-- ==========================================
-- 3. UPDATE VAULT ITEMS (Folder Linking)
-- ==========================================
ALTER TABLE public.vault_items
ADD COLUMN IF NOT EXISTS folder_id TEXT REFERENCES public.vault_folders(id) ON DELETE SET NULL;

-- Index for faster folder lookups
CREATE INDEX IF NOT EXISTS idx_vault_items_folder_id ON public.vault_items(folder_id);
CREATE INDEX IF NOT EXISTS idx_vault_folders_parent_id ON public.vault_folders(parent_id);

-- ==========================================
-- 4. REFRESH SCHEMA CACHE
-- ==========================================
-- This tells PostgREST to reload the table definitions immediately
NOTIFY pgrst, 'reload schema';
```

> [!IMPORTANT]
> **Data Integrity**: The `parent_id` and `folder_id` use `ON DELETE CASCADE` and `SET NULL` respectively to ensure that deleting a folder doesn't leave broken references.
> **UUIDs**: We use `TEXT` for IDs in the SQL to ensure 100% compatibility with the UUID strings generated by the Android app.
